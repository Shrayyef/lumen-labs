# Lumen Labs

Agency website for the Lumen Labs product suite — Aula, ServicesHub, Fileroom, and Bulduk.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Pages

- `/` — Home
- `/products` — Product index
- `/products/[slug]` — Aula, ServicesHub, Fileroom, Bulduk
- `/services` — What we do
- `/about` — Studio
- `/contact` — Contact
- `/privacy`, `/terms` — Legal stubs

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev      # development server
npm run build    # production build
npm run start    # serve production build
npm run lint     # eslint
```
